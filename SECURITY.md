# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in VeloShot, please **do not** open a public issue.

Instead, report it confidentially via GitHub's **Private Vulnerability Reporting**:
1. Go to the repository's **Security** tab on GitHub.
2. Click **Report a vulnerability** and provide reproduction steps, affected versions, and impact.

You will receive a response once the report has been reviewed, and a fix will be coordinated before public disclosure.
